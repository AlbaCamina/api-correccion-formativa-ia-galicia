# Script: Redactar un nuevo post

Cuando el usuario te pida redactar un nuevo post de LinkedIn, debes ejecutar estrictamente los siguientes pasos:

1. **Paso 1: Solicitud de Insumos.** Pregunta al usuario de qué hito técnico, ADR (ej. D-049), issue o aprendizaje quiere hablar hoy. Espera su respuesta.
2. **Paso 2: Ingesta (Silenciosa).** Una vez el usuario responda, lee el archivo `references/estrategia.md` para asegurar alineación y `assets/ejemplo_post.md` para calibrar tu estilo de escritura.
3. **Paso 3: Redacción del Borrador.** Escribe el borrador del post aplicando todas las reglas de `SKILL.md`. Incluye:
   - Sugerencia de imagen o captura de pantalla (ej. "Captura de pantalla de un test en verde").
   - El cuerpo del texto.
   - La pregunta de cierre.
   - Los hashtags.
4. **Paso 4: Feedback HitL.** Pregunta al usuario: "¿Qué te parece este enfoque? ¿Quieres que lo hagamos más técnico o más centrado en tu experiencia personal?". Itera según lo que pida.
